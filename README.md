# 付蕾 AI4Science 研究团队网站

基于 Next.js App Router 开发的静态科研团队网站。项目不依赖数据库，全部中英文内容集中在一份 JSON 配置中。

中文使用根路径，英文使用 `/en/`。两套页面拥有独立内容、导航和 SEO alternate 链接。

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:3000`。

## 生产构建

```bash
npm run typecheck
npm run build
```

生产文件输出至 `out/`。

## 内容维护

老师和团队只需要关注一个配置文件和一个资源文件夹：

- `content/content.json`：中文与英文全部内容；每个可翻译字段的 `zh` 和 `en` 紧挨着填写。

- `content/assets/`：头像、团队照片、论文封面、PDF、简历和其他附件。

配置严格按照页面顺序分为六个顶层字段：`首页`、`研究方向`、`代表成果`、`科研项目`、`团队成员`、`加入我们`。每个页面对象的前两个字段固定为 `_说明` 和 `_编辑帮助`，随后才是该页面实际使用的正文内容。构建校验会强制检查六个页面及指导字段是否齐全。

标准 JSON 不支持注释，因此 `_说明` 和 `_编辑帮助` 本身就是合法 JSON 字段；网站读取时会自动忽略它们。每个双语字段必须同时存在 `zh` 和 `en`，可以避免遗漏翻译。

团队模块使用 `团队层级 → 成员列表` 结构：层级名称可自定义，每层可添加任意多位成员，层级和成员均严格按照 JSON 数组顺序展示，不需要配置 `id` 或 `order`；内部标识自动采用对应名称的 `en`，成员为空的层级不会显示。成员的 `访问链接` 留空时仅展示卡片，填写完整网址后可点击卡片并在新窗口打开。

负责人所有校内任职与学术任职统一维护在 `首页 → 负责人信息 → 任职单位`，并集中展示在首页；科研项目配置和科研项目页面不再保存或展示另一份学术任职名单。

首页中的 `网站简称`、`导航菜单`、`首页主标题`、`首页副标题`、`首页统计` 和 `负责人信息` 均为彼此独立的字段。网站完整名称、页面简介、部署地址和资料来源不需要老师配置；导航路径根据 `导航名称.en` 自动匹配。

具有具体业务含义的字段尽量采用中文，例如 `名称`、`角色`、`导师类别`、`导航名称`、`数量`、`类别`、`方向名称`、`项目经费`、`首页推荐`、`层级名称`、`成员名称`、`成员列表`；`zh` 和 `en` 等通用语言字段保持英文。研究方向卡片的锚点和配色会按照内容顺序自动生成，无需手动配置。

研究方向支持可选的 `链接` 字段。填写完整网址后，中文和英文页面点击该方向都会在新窗口打开该网址；不需要外部链接时保留空字符串或省略该字段，首页卡片仍会跳转到站内研究方向详情。例如：

```json
"链接": "https://example.edu/research/project-page"
```

代表成果中的 `访问链接` 采用相同规则：留空或省略时仅展示成果，填写完整网址后，首页推荐成果与代表成果列表均可点击并在新窗口打开。

科研项目也支持可选的 `访问链接`：填写后，首页项目卡片和科研项目列表均可点击并在新窗口打开；留空或省略时仅展示项目内容。

老师只需要关注整个 `content/` 目录，不需要进入 `src/` 或 `public/`。图片和附件放入 `content/assets/` 后，在配置中填写与目录完全对应的 `/content/assets/文件名`。子目录也会原样保留，例如 `content/assets/team/student-a.jpg` 对应 `/content/assets/team/student-a.jpg`。运行 `npm run dev` 或 `npm run build` 时，项目会自动把资源同步到网站公开目录。

例如：

```json
"头像": "/content/assets/lei-fu.png"
```

招生正文支持 Markdown，并以内容块数组写在唯一 JSON 配置的 `加入我们 → 正文 → zh/en` 中。每个字符串填写一个标题、段落、列表项或引用；代码会自动在不同内容块之间插入空行，并让连续列表项保持在同一列表中，因此无需配置空字符串。编辑 JSON 时请注意最后一个数组元素后面不能添加逗号。

每次构建都会通过 Zod 校验 JSON 字段。字段缺失或类型错误时构建会直接失败，避免发布不完整内容。

## 免费部署

这是纯静态站点，可部署到 Cloudflare Pages、EdgeOne Pages、Netlify、Vercel 或 GitHub Pages。

推荐配置：

- 构建命令：`npm run build`
- 输出目录：`out`
- Node.js：22

Netlify 构建时会自动提供部署域名，项目会使用该环境地址生成 canonical、robots 和 sitemap，无需在内容配置中维护网站地址。平台提供的免费 `.netlify.app` 二级域名可以直接使用；后续也可以绑定学校子域名。
